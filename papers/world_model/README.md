## 关键概念

- **世界模型**：预测未来帧/未来状态，能够想象未发生的场景
- **数据引擎/数据闭环**：用世界模型生成数据，不断训练提升模型
- **想象训练**：在世界模型的想象中做强化学习/规划训练
